# [JCR1 Zone Optimization and Improvement] SCNGO-TCN-Attention Data Classification Prediction Program.

[JCR1 Region Optimization] SCNGO-TCN-Attention Data Classification Prediction Program.
Program Platform: Requirements for Matlab 2023 or above.
Code Explanation: A data classification prediction program based on the Northern Goshawk Optimization Algorithm (NGO), Time Convolutional Neural Network (TCN) integrated with attention mechanism, using the SCNGO algorithm. This algorithm is currently not documented in literature to improve upon.
The Northern Goshawk Optimization Algorithm (NGO) was formally proposed by MOHAMMAD DEHGHANI et al. in 2022. The algorithm simulates the hunting process of the Northern Goshawk (recognition and attack of prey, pursuit and escape).
Improvement strategies are referenced from the Sparrow Optimization Algorithm, with the following improvements:
① Use the Transmitted Backward Learning strategy to initialize the individual of the Northern Goshawk Algorithm, where the basic idea is to expand the search range by calculating the reverse solution of the current solution to find a better candidate solution for the given problem;
② Replace the position update formula in the scouting phase of the original Goshawk Algorithm with the positive cosine strategy;
③ Improve the step size search factor of the positive cosine strategy; the original step size search factor follows a linear declining trend, which is not conducive to further balancing the global search and local development capabilities of the Northern Goshawk Algorithm.
Functions:
1. Single variable feature input, input one row (feature), each feature length is M.
2. Optimize learning rate, convolution kernel size, number of neurons through the SCNGO optimization algorithm, aiming to achieve the highest accuracy on the test set as the objective function.
3. Plot: Loss and Accuracy iterative change polar coordinates graph; Test comparison point plot, confusion matrix graph; Fitness curve (if the initial accuracy is the highest, then the fitness curve is a horizontal line).
4. Display: Accuracy, recall rate, precision rate, F1 score, etc.
Applicable to various data classification scenarios, such as rolling bearing faults, transformer oil and gas faults, power system transmission line fault areas, insulators, distribution networks, and disturbances of electric energy quality. It is used for identification, diagnosis, and classification in these fields.
Easy to use:  
Directly import data into an Excel table without needing to make significant modifications to the program. The internal documentation is detailed and easy to understand.
